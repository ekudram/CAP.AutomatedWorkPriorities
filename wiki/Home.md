# [CAP] Automated Work Priorities

RimWorld **1.6** mod that writes vanilla Work priorities (0–4) from **jobs**, **rules**, and **presets**.

- **License:** [MIT](https://github.com/ekudram/CAP.AutomatedWorkPriorities/blob/main/LICENSE)
- **Source:** https://github.com/ekudram/CAP.AutomatedWorkPriorities

On load the log should show: `[CAP] Automated Work Priorities loaded`

## Quick start

1. Subscribe to **Harmony**. Enable this mod after Harmony.
2. If you use **[FSF] Complex Jobs**, load it **before** this mod.
3. Do **not** also enable Automated Work Assignment.
4. Open a colony → Work tab → **Auto: ON** → **Settings**.

The settings window remembers size and position (RimWorld ModSettings, not the save).
