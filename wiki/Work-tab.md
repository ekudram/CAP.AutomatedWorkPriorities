# Work tab

Three buttons (hover for tooltips):

| Button | Meaning |
|--------|---------|
| **Auto: ON/OFF** (green / red) | When ON, the mod writes priorities and **re-applies at dawn**. Same as Settings → Auto. |
| **Refresh** | Apply Jobs, Rules, and the current preset **now**. |
| **Settings** | Open the settings window. |

## Settings header

| Button | Meaning |
|--------|---------|
| **Auto** | Same as Work tab Auto. Dawn refresh is included. |
| **Emergency** | Firefighter, Doctor, Childcare, Patient, and Bed rest forced to **P1**. Ban/Only still apply. |
