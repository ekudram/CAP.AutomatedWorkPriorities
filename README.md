# [CAP] Automated Work Priorities

RimWorld **1.6** mod that assigns colonist (and slave) work priorities from **jobs**, **rules**, and **presets**.

**License:** [MIT](LICENSE)

**Wiki:** https://github.com/ekudram/CAP.AutomatedWorkPriorities/wiki

## Requirements

- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld 1.6

Load **after** Harmony, Biotech (if you have it), and **[FSF] Complex Jobs** (if you use it).

Do **not** run together with Automated Work Assignment — both write the same Work grid.

On load you should see: `[CAP] Automated Work Priorities loaded`

## Build

Open `CAP.AutomatedWorkPriorities.sln` in Visual Studio. Release output:

`../1.6/Assemblies/CAP_AutomatedWorkPriorities.dll`

The playable mod folder is the parent of this `Source` directory (`About`, `1.6`, `Languages`).
